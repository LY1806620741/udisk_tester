# udisk_tester

开源 U 盘校验测速工具（Rust / egui 版，仿 H2testw）。

[![CI](https://github.com/LY1806620741/udisk_tester/actions/workflows/ci.yml/badge.svg)](https://github.com/LY1806620741/udisk_tester/actions)
[![Release](https://img.shields.io/github/v/release/LY1806620741/udisk_tester)](https://github.com/LY1806620741/udisk_tester/releases)

## 功能

- **全盘读写校验**：向 U 盘写入随机数据并回读比对，检测扩容盘 / 坏块（H2testw 同款原理）
- **简易测速**：连续读 / 写 100MB + 4K 随机读 / 写各 20000 次，输出各阶段 MB/s
- **USB 信息查询**：读取 U 盘设备的 VID / PID
- 图形界面（egui），带实时进度条与运行日志

## 下载使用（Windows）

无需安装 Rust 或任何运行时。从 [Releases](https://github.com/LY1806620741/udisk_tester/releases) 下载
`udisk_tester-windows-x64.zip`，解压后双击 `udisk_tester.exe` 即可使用。

> 建议在 Windows 10 / 11（x64）上使用。

## 使用教程

界面顶部为三个标签页：**全盘校验**、**简易测速**、**USB 信息**；底部为进度条与运行日志区。

```
┌─────────────────────────────────────────────┐
│ [全盘校验]  [简易测速]  [USB 信息]           │
├─────────────────────────────────────────────┤
│  盘符：(○ E:  ○ F:  ○ G:)  [刷新盘符]       │
│  单文件大小 MB：[1024]                       │
│  [全盘写入+校验] [停止] [清理测试文件]       │
│  ⚠ 全盘校验会持续写入所选盘符直至仅剩约      │
│    100MB 空间；请确认盘符无误、数据已备份。  │
├─────────────────────────────────────────────┤
│  写入阶段 ▓▓▓▓▓▓░░░░░░  45%                 │
├─────────────────────────────────────────────┤
│  运行日志：                                  │
│  ===== 全盘读写校验开始 =====                 │
│  写入 E:\test_1.h2w ...                      │
└─────────────────────────────────────────────┘
```

### ① 全盘校验（检测扩容盘 / 坏块）

1. 插入 U 盘，在 **盘符** 中选中目标盘（或点击 **刷新盘符** 重新枚举）
2. 设置 **单文件大小 MB**（默认 1024，范围 100–4096）
3. 点击 **全盘写入+校验**：工具持续写入 `test_*.h2w` 文件，直到盘上仅剩约 100MB 空间，再逐文件回读并比对哈希
4. 查看结果：
   - `✅ 全部校验通过` → 数据可完整写读，盘可用
   - `❌ 检测到数据损坏：扩容盘 / 闪存坏块` → 写入与回读不一致，U 盘有质量问题
5. 测试完成后点击 **清理测试文件** 删除 `test_*.h2w`

> ⚠️ 校验会写满所选盘符，运行前请确认盘符无误、重要数据已备份。C 盘不会出现在盘符列表中。

### ② 简易测速

1. 选中盘符，点击 **开始测速（连续+4K）**
2. 依次执行：连续写入 100MB → 连续读取 → 4K 随机写入 20000 次 → 4K 随机读取，并输出各阶段 MB/s
3. 临时文件为 `bench_test.tmp`，可点击 **清理测速临时文件** 删除

### ③ USB 信息

点击 **读取USB VID/PID** 获取设备的 VID/PID，再到 ChipGenius 等数据库查询主控型号。
（本工具无法直接读取闪存颗粒信息。）

## 从源码构建

需要 [Rust](https://rustup.rs/)（stable）：

```bash
cargo build --release
./target/release/udisk_tester
```

## 运行测试

```bash
cargo test
```

## CI 与发布

- GitHub Actions 在 Windows / macOS / Ubuntu 三平台自动执行 `cargo test` 与 `cargo build --release`
- 推送 tag（如 `v0.2.0`）自动构建并发布 Windows 版 zip 到 Releases

## 安全提示

- 全盘校验会写满目标盘符，请仅对确认可覆盖数据的 U 盘使用
- 临时文件命名固定为 `test_*.h2w` / `bench_test.tmp`，如目标盘已存在同名文件将被覆盖（工具会记录警告）
- 校验中途可随时点击 **停止**，写入与校验阶段均会快速响应
